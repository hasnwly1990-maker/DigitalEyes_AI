# مبشر (Mubasher) - رفيقك الذكي في رحلة الإيمان 🕋

واجهة ويب متجاوبة وموجهة للهواتف الذكية (Mobile-First) لمشروع إنترنت الأشياء والذكاء الاصطناعي **مبشر**، المخصص لإرشاد ضيوف الرحمن وتسهيل حركتهم عبر الكاميرا الذكية (ESP32-CAM) والتوجيه الصوتي.

---

## 🌟 الميزات الرئيسية

1. **واجهة مخصصة للهواتف وسهلة الوصول (Accessibility-first):**
   - خطوط واضحة وكبيرة وألوان مريحة وعالية التباين (الأبيض، الأزرق الداكن `#0B192C`، والأخضر الزمردي `#059669`).
   - دعم كامل للغة العربية واتجاه الكتابة من اليمين إلى اليسار (`dir="rtl"`).

2. **شاشة بث الكاميرا (ESP32-CAM Stream):**
   - حاوية بنسبة أبعاد 4:3 مع زوايا منحنية وخلفية داكنة.
   - شارة بث حي نابضة باللون الأحمر `LIVE`.
   - معرّف (`id="camera-stream-container"`) لربط بث الفيديو المباشر من ESP32-CAM بكل سهولة.

3. **لوحة حالة الذكاء الاصطناعي والتوجيه الصوتي:**
   - صندوق تنبيه بارز (`id="ai-status-text"`) لعرض التوجيهات فورياً.
   - تأثير كتابة تدريجي سلس (Typewriter Effect) لكل تنبيه.
   - دعم تحويل النص إلى كلام (Text-to-Speech) باللغة العربية ونغمات إشعار تفاعلية.

4. **شبكة أزرار التحكم والاستشعار (2x2 Grid):**
   - **رادار بشري ذكي** (`fa-tower-broadcast`): كشف مسارات الزحام وتحديد الممرات الآمنة.
   - **تحليل المعالم** (`fa-kaaba`): التعرف على المعالم والكعبة ومقام إبراهيم وحساب المسافات.
   - **منع الضياع** (`fa-users`): تتبع الفوج ورصد موقع المطوف.
   - **التوجيه الصوتي** (`fa-volume-high`): تفعيل نظام الصوت المكاني ثلاثي الأبعاد.

## 🚀 كيفية تشغيل المشروع

1. افتح الملف مباشرة في أي متصفح (Chrome, Edge, Safari):
   ```bash
   C:\مبشر (MUBASHER)\index.html
   ```

2. أو تشغيل سيرفر محلي (اختياري عبر Python أو Node.js):
   ```powershell
   # باستخدام Python
   python -m http.server 8000
   ```
   ثم فتح الرابط: `http://localhost:8000`

## 📡 ربط بث كاميرا ESP32-CAM

عند توفر رابط البث المباشر (MJPEG stream من ESP32-CAM مثل `http://192.168.1.50:81/stream`)، يمكنك استبدال العنصر الداخلي لحاوية الكاميرا بصورة بث أو وسم فيديو عبر الجافاسكريبت:

```javascript
const cameraContainer = document.getElementById('camera-stream-container');
cameraContainer.innerHTML = `
  <img src="http://<ESP32_IP>:81/stream" 
       alt="بث مباشر ESP32-CAM" 
       class="w-full h-full object-cover rounded-2xl" />
`;
```
